## Use the confirmation

In **Saved in this browser**, preview the saved week you intend to remove, then choose **Remove saved week**. The inline review names that stored copy. **Keep saved copy** cancels; **Confirm removal** submits the existing removal transaction for that captured selection once. Removing a saved copy does not remove the week currently open in the planner or its venue notes. Retain a portable week file or collection backup first if you may need the copy again; confirmation does not create a backup or an undo history.

The [adopted guide](https://github.com/Jacob-Met/tastetable/blob/bb1f59a9cbb9e3569481edee4bfc58b0ad600040/docs/SAVED_WEEK_REMOVAL_CONFIRMATION.md) explains cancellation, stale-selection retirement, storage refusal and compatibility with older component hosts. Its **Receiving status and ownership** section is the preserved historical component account. The current integration result is recorded below. Adopting source does not install a package or change a running browser session.

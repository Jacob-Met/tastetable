# TasteTable — current result

[Download and run v0.3.12 visit history](https://github.com/Jacob-Met/tastetable/releases/tag/v0.3.12-visit-history) · [Phone screen](https://github.com/Jacob-Met/tastetable/releases/download/v0.3.12-visit-history/working-week-phone.png) · [Desktop screen](https://github.com/Jacob-Met/tastetable/releases/download/v0.3.12-visit-history/working-week-desktop.png)

A caregiver can read the seven-day plan, save it privately, add a reply on a dated visit, return to that visit and reopen the complete saved week. Original care checks appear beside each suggested visit as questions to confirm with the venue. Use previous visits opens the existing private history importer from the week itself. Accepted records mark both completed and missed trips beside the next matching choice. Infrequent file and calendar controls are folded away. The runnable package uses fictional fixture venues.
